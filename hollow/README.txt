# THE HOLLOW — Build 01

This is a separate playable prototype. It does not modify the existing NOCTURNE VOID website or script.js.

## Files
- `index.html` — standalone test page
- `hollow.js` — Three.js game prototype
- `hollow.css` — game HUD and menus

## Run it
1. Upload the entire `hollow` folder to your GitHub Pages repository as a new folder named `hollow`.
2. Wait for GitHub Pages to publish.
3. Open: `https://nightclubvirus-bit.github.io/Nocturne-Void/hollow/`
4. Click DEPLOY. Click the game view if the mouse does not lock.

Internet is required because Three.js is loaded from jsDelivr.

## Controls
- WASD / arrow keys: move
- Mouse: look
- Shift: sprint
- E: interact
- Left click: fire
- R: reload
- Esc: release mouse / pause overlay
- Mobile: on-screen movement and action buttons

## Current objective chain
1. Find the security key.
2. Restore emergency power.
3. Neutralize the hostile.
4. Reach extraction.

## Important
This is the first playable foundation, not the final realistic asset pass. The enemy, weapon, and hospital props are low-poly placeholders. The next development pass should replace them with optimized models, animations, audio, improved collision, and a more advanced enemy state machine. Test in a new folder first; do not replace the current `script.js`.
